## 三、首页模块（共 7 个模块）

### 3.1 Hero 轮播区
- 全宽轮播，自动切换 5 秒；电脑端/手机端两套独立列表，每端建议不超过 15 张（2026-08-13 老板拍板：15 张/端，不行以后再调；文字留空则不显示文字层）
- 标题 + 标语叠加在图上（留空则不显示）
- 桌面端：大图 12:5 横图比例（如 1920×800）；移动端：适配图 5:6 竖图比例（如 750×900）
- ★即时加载（eager loading），首屏不需要懒加载

### 3.2 ★ B2B 产品入口卡片
```
┌─────────────────────────────────┐
│         📦 B2B产品               │
│     批发客户专属产品展示          │
│                         [进入→] │
└─────────────────────────────────┘
```
- 位置：认证展示区之后、客户评价之前
- 所有人可见，无需登录
- 点击跳转 `/b2b`
- ★和老版区别：入口卡片名称从"📱 线下产品展示区"改为"📦 B2B产品"

### 3.3 分类卡片区
- 8 个一级分类，带背景图 + 名称
- 网格布局：桌面 4 列 → 平板 3 列 → 手机 2 列

### 3.4 卖点展示区
- 3-4 个卖点，图标 + 标题 + 描述
- 桌面横排，手机竖排

### 3.5 认证展示区
- 认证证书图片轮播
- 桌面 3 列，手机 1 列

### 3.6 客户评价区
- 已审核的评价卡片，含客户名、国家、评分、内容
- 桌面 3 列，手机 1 列

### 3.7 CTA 行动区
- "立即询价" + "申请样品" 两个按钮
- 深绿背景 + 白色按钮

│  │   自包装成品礼盒        │ │  Bence   │ │

**卡片规格：**

- 悬停：微微放大 + 暖金边框 + 阴影
- 点击 → 弹出密码验证弹窗

### 4.2 密码验证弹窗 (B2BPasswordModal)

```
┌─ 密码验证 ───────────────────── ✕ ──────┐
│              🔒                          │
│       自包装成品礼盒                      │
│     请输入访问密码查看产品                 │
│                                         │
│  ┌───────────────────────────────┐      │
│  │ 请输入密码              👁️    │      │
│  └───────────────────────────────┘      │
│                                         │
│  [            确    认            ]      │
│                                         │
│  没有密码？请联系销售人员获取              │
└─────────────────────────────────────────┘
```

**关键规格：**
- `autocomplete="off"` 禁止浏览器保存密码
- 👁️ 眼睛图标切换明文/密文
- 密码错误：红色提示 2 秒后消失
- 5 次错误：锁定 30 分钟
- 桌面端弹窗 400px 宽，手机端全屏

## 五、产品详情页

### 5.1 默认布局（未设置自定义布局时）

```
┌─────────────────────────────────────────┐
│   图片轮播（左）  │  产品信息（右）         │
│   支持缩放+左右切 │  名称/价格/规格/询价按钮 │
├─────────────────────────────────────────┤
│   产品描述                               │
├─────────────────────────────────────────┤
│   ★视频/360°展示（如有上传）              │
├─────────────────────────────────────────┤
│   冲泡指南                               │
├─────────────────────────────────────────┤
│   产品规格表                             │
├─────────────────────────────────────────┤
│   推荐产品（最多3个）                     │
└─────────────────────────────────────────┘
```

### 5.2 自定义布局（后台设置了拖拽布局时）

7 种区块类型按后台设置的顺序排列：
- `imageGallery`（图片轮播）
- `productInfo`（产品信息：名称/价格/按钮）
- `description`（产品描述）
- `brewingGuide`（冲泡指南）
- `video`（视频/360°展示）
- `specs`（规格参数）
- `recommended`（推荐产品）

### 5.3 ★视频/360°展示区块

- 视频：video.js 播放器，支持全屏、倍速
- 360°：上传 24-36 张连续角度图，鼠标/手指拖拽旋转切换
- 该区块仅在至少有一个视频/360°资源时显示

## 六、展示区独立详情页 (`/showcase/[slug]`)

- **无导航栏、无页脚**（老规则不变）
- 内容同产品详情页
- 价格显示/隐藏由 `showPriceInShowcase` 控制
- 语言切换器独立（不影响网站其他页面）
- ★添加 `noindex` meta 标签（不被搜索收录）
