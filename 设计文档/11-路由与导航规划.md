## 一、前台 URL（多语言路由）

> 格式：`/[locale]/页面路径`，英文不加前缀（默认语言）

| 页面 | 中文 | 英文（默认） | 认证 |
|:-----|:-----|:-----|:-----|
| 首页 | `/` | `/en` | 否 |
| 产品列表 | `/products?cat=xxx` | `/en/products?cat=xxx` | 否 |
| 产品详情 | `/products/{slug}` | `/en/products/{slug}` | 否 |
| ★B2B入口 | `/b2b` | `/en/b2b` | 否 |
| ★B2B分类产品 | `/b2b/{categorySlug}` | `/en/b2b/{categorySlug}` | ★B2B密码 |
| 展示区独立详情 | `/showcase/{slug}` | `/en/showcase/{slug}` | 否 |
| 产品对比 | `/compare?ids=a,b` | `/en/compare?ids=a,b` | 否 |
| ★样品申请 | `/sample` | `/en/sample` | 否 |
| 关于我们 | `/about` | `/en/about` | 否 |
| 认证资质 | `/certifications` | `/en/certifications` | 否 |
| 联系我们 | `/contact` | `/en/contact` | 否 |
| 隐私政策 | `/privacy` | `/en/privacy` | 否 |
| 服务条款 | `/terms` | `/en/terms` | 否 |
| ★客户聊天 | `/chat?token=***` | — | 否(token) |

> 📝 施工中变更：①实际所有语言均带前缀（含英文 /en），根路径 / 由中间件按 IP/Cookie 重定向到对应语言；②无独立 /chat 路由——客户聊天为全站浮动挂件（ChatWidget，询价后凭 chatToken 对话）

## 三、中间件路由拦截逻辑

```
请求 → middleware.ts
  │
  ├── /admin/* ？
  │   ├── /admin（登录页）→ 放行
  │   └── 其他后台页 → 检查 Cookie auth_token
  │       ├── 有效 → 放行（+ lastActivityAt 更新）
  │       └── 无效/过期 → 重定向 /admin?expired=1
  │
  ├── /api/* → 放行（各 API 路由自行鉴权）
  │
  ├── /b2b/* → 放行（前端自行检查 localStorage token）
  │
  ├── /showcase/* → 放行（前端页面，无需服务端鉴权）
  │
  └── 前台页面 → IP 检测中间件
      ├── Cookie 有语言选择 → 用 Cookie 语言
      └── 无 → request.cf.country 判断 → 写 Cookie → 重定向到对应语言
```

## 四、sitemap.xml 和 robots.txt

### sitemap.xml 包含

```
https://yiquantea.com/ （每周）
https://yiquantea.com/products/* （每天）
https://yiquantea.com/about / certifications / contact / sample / privacy / terms
```
**不含**：`/b2b/*` `/showcase/*` `/admin/*` `/api/*` `/chat/*`

> 📝 施工中变更：sitemap 由 src/app/sitemap.ts 生成（阶段 19），实际内容为六语言 × 主路由（首页/产品列表/样品/关于/认证/联系/隐私/条款）+ 全部上架产品详情（均带语言前缀）；不含清单与上文一致（无 /chat 路由）

### robots.txt

```
User-agent: *
Allow: /
Disallow: /admin/
Disallow: /api/
Disallow: /showcase/
Disallow: /b2b/
Disallow: /chat/
Sitemap: https://yiquantea.com/sitemap.xml
```

> 📝 施工中变更：实际 robots.txt 由 src/app/robots.ts 生成（阶段 19），Disallow 仅四项（/admin/ /api/ /b2b/ /showcase/），无 /chat/（本站无该路由）
