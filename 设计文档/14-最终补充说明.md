## 一、安全方案

### 1.1 API 限流

| 接口类型 | 限制 | 时间窗口 | 实现 |
|:-----|:-----|:-----|:-----|
| 公开读取 | 60 次 | 1 分钟 / IP | KV 计数 |
| 登录 | 5 次 | 1 分钟 / IP | KV 计数 |
| B2B 密码 | 5 次 | 30 分钟 / IP | KV 计数 |
| 询价提交 | 3 次 | 5 分钟 / IP | KV 计数 |
| 文件上传 | 10 次 | 1 分钟 / IP | KV 计数 |

### 1.2 人机验证

- 询价表单 + 样品申请：hCaptcha
- 后台登录：不做人机验证（已有 5 次锁定机制）
- 预留 Turnstile 切换接口（一行配置切）

### 1.3 密码安全

| 类型 | 加密 | 可逆 |
|:-----|:-----|:-----|
| 后台登录密码 | SHA-256（Web Crypto API） | 不可逆 |
| B2B 分类密码 | AES-256-CBC | 可逆（admin 二次验证后查看明文） |
| B2B 访问 Token | crypto.randomUUID() + KV 存储 | 24 小时过期 |

### 1.4 XSS/SQL 注入防护

- 用户输入 escapeHtml 转义
- Drizzle 参数化查询（天然防 SQL 注入）
- CSP 响应头（next.config.mjs 配置）

## 二、GDPR 合规

| 项目 | 内容 |
|:-----|:-----|
| 触发条件 | IP 在欧盟/EEA 国家 + 无同意记录 |
| Cookie 分类 | 必要（始终启用）/ 分析 / 营销 |
| 同意记录 | Neon 数据库（gdpr_consents 表） |
| 撤回同意 | 隐私政策页提供链接 |
| 数据删除请求 | 邮箱 yqtea.cn@gmail.com |

## 三、运维方案

### 3.1 备份恢复

| 方式 | 说明 |
|:-----|:-----|
| **Neon PITR**（时间点恢复） | 免费 6 小时恢复窗口，应对误操作 |
| **R2 冷备** | Workers Cron 每天凌晨 3 点导出 SQL 存 R2，保留 7 天 |
| **手动备份** | 后台一键触发 |

### 3.2 部署流程

1. 代码推送到 GitHub → Cloudflare Pages 自动构建部署
2. Workers 通过 `wrangler deploy` 独立部署
3. 回滚：Pages 后台点一下回滚到上一版本，1-2 分钟生效

### 3.3 监控

- Cloudflare Pages 自带部署状态
- Workers 自带日志（`wrangler tail`）
- Neon 自带数据库监控面板
- 建议额外接入 UptimeRobot（免费）监控网站可用性

## 四、sitemap.xml 和 robots.txt

**sitemap 包含**：首页 / 产品列表 / 产品详情 / 静态页（about/certs/contact/sample/privacy/terms）

**sitemap 不含**：`/b2b/*` `/showcase/*` `/admin/*` `/chat/*`

**robots.txt**：Allow `/`；Disallow `/admin/` `/api/` `/showcase/` `/b2b/` `/chat/`

## 五、hreflang 标签

所有多语言页面输出 hreflang 标签，示例：
```html
<link rel="alternate" hreflang="zh" href="https://yiquantea.com/products/slug" />
<link rel="alternate" hreflang="en" href="https://yiquantea.com/en/products/slug" />
<link rel="alternate" hreflang="x-default" href="https://yiquantea.com/en/products/slug" />
```

## 六、依赖安全现状

- 本项目从零重写，无历史包的遗留漏洞
- Drizzle + Neon 驱动已是 Edge Runtime 原生
- 无 node-cron / bcrypt / geoip-lite / sharp 等废弃依赖

## 七、与老版的关键差异总结

| 维度 | 老版 v3.0 | 新版 | 谁受影响 |
|:-----|:-----|:-----|:-----|
| 底层技术 | Node.js + Docker + Prisma | Cloudflare Workers + Drizzle + Neon | 开发者 |
| 部署方式 | Docker Compose | Cloudflare Pages + Wrangler | 开发者 |
| 数据库 | 自建 PostgreSQL | Neon Serverless PostgreSQL | 无感知 |
| 缓存 | Redis | KV | 无感知 |
| 文件存储 | 本地 + OSS | R2 | 无感知 |
| 认证 | NextAuth.js | jose + JWT | 无感知 |
| 后台界面 | — | — | **完全一样** |
| 前台体验 | — | — | **完全一样**，更快 |
