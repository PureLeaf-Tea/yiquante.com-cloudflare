# 懿泉茶业 YiQuanTea.com — 多语言翻译字典

> **版本**: v1.0（Cloudflare 全栈版） | **日期**: 2026-08-11
>
> **本文档定位**：6 语言翻译文件的"完整钥匙清单"——每个翻译键在 6 种语言中对应的文字。
> **阅读对象**：开发人员（编写 messages/*.json）+ 运营人员（了解有哪些翻译文本）。

---

## 一、翻译文件结构

```
messages/
├── en.json    # 英文（默认语言，完整翻译）
├── zh.json    # 中文（完整翻译）
├── ru.json    # 俄文（核心翻译 + 英文 fallback）
├── de.json    # 德文（核心翻译 + 英文 fallback）
├── es.json    # 西班牙文（核心翻译 + 英文 fallback）
└── fr.json    # 法文（核心翻译 + 英文 fallback）
```

> 实际约 108 个主键 + 230 个叶子键。以下列出核心键分类和示例。

## 三、非中英文语言的处理策略

俄/德/西/法 4 种语言：优先翻译核心键（导航、B2B 密码、询价表单、产品信息），其余键 fallback 到英文。在 `next-intl` 配置中设置 `fallbackLocale: 'en'`。
