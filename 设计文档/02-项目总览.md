## 二、员工操作指引

> 面向日常操作后台的员工，明确哪些操作没变、哪些有微调。

### 2.1 完全不用重新学的地方（99% 的操作都在这里）

- **产品添加/编辑/删除**：和以前一模一样。找到产品 → 点编辑 → 修改 → 保存。没有任何变化。
- **B2B 展示区管理**：添加分类 → 设密码 → 在编辑产品时勾选展示区分类。操作流程完全相同。
- **询价回复**：左侧点询价 → 右侧聊天窗口 → 打字 → 发送。微信风格布局不变。
- **样品处理**：列表筛选 → 点查看详情 → 改状态 → 保存。一模一样。
- **首页编辑、导航编辑、网站设置**：所有配置项的位置、操作方式不变。

### 2.2 有微调的地方（仅此一条）

| 操作 | 微调说明 |
|:-----|:-----|
| **备份管理** | 页面还是那个页面（`/admin/backup`），但备份恢复不再需要开发人员介入。后台点"手动备份"即可，出问题后联系管理员在 Neon 控制台用"时间点恢复"功能自行恢复，不需要懂技术。 |

### 2.3 后台快捷搜索（全局搜索框）

后台右上角搜索框，输入关键词直接跳转。新增以下可搜索关键词：

## 三、常见问题自查

> 操作过程中遇到下面这些问题，不需要问技术，自己先按提示排查。

### Q1：上传产品图片后，前台不显示？
- 先检查：后台产品编辑页 → 图片标签页 → 图片是否真的上传成功（有预览图即为成功）
- 再等等：如果是刚上传的，最多等 1-2 分钟（CDN 缓存刷新）
- 还不行：联系管理员检查 R2 存储桶配置

### Q2：B2B 产品区，客户说密码输对了但进不去？
- 检查密码：去展示区管理页 → 找到该分类 → 点 🔑 密码 → 查看明文确认密码没错
- 检查 token：提醒客户清除浏览器缓存，或者换一个浏览器试试
- 锁定状态：如果提示"30 分钟后再试"，说明客户输错太多次被锁了，等 30 分钟自动解

### Q3：后台登录时提示"账号已锁定"？
- 等 15 分钟：输错 5 次密码会自动锁定 15 分钟，到时间自动解
- 等不了：联系管理员在后台员工管理里手动解除锁定

### Q4：客户说聊天消息发了我们收不到？
- 刷新页面：可能是页面没及时刷新，按 F5 刷新一下聊天页
- 检查状态：确认该询价的状态不是"已关闭"
- 再不行：让客户重新提交一个询价（老的不会被覆盖）

### Q5：样品申请的记录找不到了？
- 检查筛选：看看筛选条件是不是选在"新申请"上，切换到"全部"试试
- 检查日期：确认没有把时间范围筛太窄

## 七、技术架构（新版）

### 7.1 一句话总结

```
把网站拆成网页（Pages）+ 后台逻辑（Workers）+ 业务数据库（Neon Postgres）
+ 缓存（KV）+ 轻量配置（D1）+ 文件存储（R2）+ 图片处理（Images），
全部跑在 Cloudflare 全球网络里，不设任何自有服务器。
```

### 7.2 架构分层

```
┌─────────────────────────────────────────────────────┐
│                   客户/员工 浏览器                       │
└────────────────────────┬────────────────────────────┘
                         │ HTTPS
                         ▼
┌─────────────────────────────────────────────────────┐
│                Cloudflare DNS（域名·SSL·防护）          │
└────────┬────────────────────────────────────────────┘
         │
    ┌────┴────────────┐
    ▼                 ▼
┌────────┐    ┌──────────────┐
│ Pages  │    │   Workers    │  ← 用户能直接打交道的两层
│(网页)  │    │  (后台逻辑)   │
└────────┘    └───┬────┬─────┘
                  │    │
      ┌───────────┼────┼────────────┐
      ▼           ▼    ▼            ▼
  ┌──────┐  ┌────┐ ┌──┐ ┌──────────┐
  │ Neon │  │ KV │ │D1│ │   R2     │
  │Postgres│ │缓存│ │轻量│ │ 文件仓库  │
  └──────┘  └────┘ └──┘ └────┬─────┘
                             ▼
                      ┌──────────────┐
                      │  Images      │
                      │  (图片处理)   │
                      └──────────────┘
```

### 7.3 核心技术选型

| 层 | 老版 v3.0 | 新版 Cloudflare 版 | 换了的原因 |
|:---|:-----|:-----|:-----|
| 前端框架 | Next.js 14 | **Next.js 14**（不变） | 稳定，现有经验能用上 |
| 样式 | Tailwind CSS + shadcn/ui | **Tailwind CSS + shadcn/ui**（不变） | 纯前端，不受影响 |
| ORM | Prisma | **Drizzle ORM** | Prisma 在 Workers 上跑不了；Drizzle 天生支持 Edge Runtime，免费 |
| 数据库 | PostgreSQL（Docker） | **Neon Serverless PostgreSQL** | 云端托管，不用自己装和调优，自带时间点恢复 |
| 缓存 | Redis | **Cloudflare KV** | 全球同步，延迟更低；数据自动同步到所有节点 |
| 轻量数据 | — | **Cloudflare D1**（新增） | 站点配置、GDPR 等小数据用这个存，不占主库资源 |
| 文件存储 | 本地磁盘 + OSS | **Cloudflare R2** | 不限出口流量费，国际访问更快 |
| 图片处理 | sharp（Node 库） | **Cloudflare Images** | 自动压缩、格式转换，不用在代码里手动处理 |
| 认证 | NextAuth.js v5 | **jose（JWT 自写）** | 轻量、透明、好调试，适配 B2B 权限更灵活 |
| 定时任务 | node-cron | **Workers Cron Triggers** | Cloudflare 原生，不需要在代码里跑定时器 |
| 邮件 | 未实现 | **Resend API** | 纯 HTTP 接口，Workers 原生支持；发件人 YiQuanTea <no-reply@yiquantea.com> |
| 部署 | Docker + Nginx | **Cloudflare Pages** | 代码推 GitHub 自动部署，不用配服务器 |

> 📝 施工中变更：邮件实际采用 Resend API（src/lib/email.ts），未使用原定的 Gmail SMTP

## 九、设计原则

### 9.1 工程质量优先
- **本项目不赶工期**。在"快"与"对"之间必须选"对"
- 每个模块完成后必须可独立验证
- 数据操作必须有错误处理和验证
- 数据库写入必须有事务保护

### 9.2 移动端优先
- 所有前台页面必须先适配移动端（<768px），再适配桌面端
- 按钮最小触摸尺寸 48×48px
- 导航在移动端切换为汉堡菜单
- B2B 密码弹窗在移动端全屏显示

### 9.3 品牌视觉一致性
- 所有页面统一使用品牌色、字体、按钮样式
- 品牌主色：深绿 `#1a3a1a`
- 品牌辅色：暖金 `#c9aa7b`
- 页面底色：奶油白 `#fdfbf7`

### 9.4 安全性
- 所有用户输入必须转义（防 XSS 攻击）
- API 接口必须做权限校验（除公开接口外）
- 密码使用 Web Crypto API 哈希存储
- 文件上传限制类型和大小（含视频白名单）
- API 限流：公开接口 60 次/分钟，登录 5 次/分钟
- B2B 密码保护：5 次错误锁定 30 分钟
- 后台会话超时：1 小时无操作自动退出
- 表单人机验证：询价/样品提交使用 hCaptcha

### 9.5 数据完整性
- 删除分类时产品自动移入"00 未分类"
- 有子分类的父分类不能直接存放产品
- 分类名称同级不可重复
- 删除 B2B 展示区分类时，关联的产品不删除（仅解除关联）

### 9.6 B2B 展示区隔离
- 展示区独立详情页无导航栏、无页脚
- B2B 入口（/b2b）公开访问，分类卡片无需密码
- 每个 B2B 分类独立密码保护
- 密码验证后签发 24 小时有效 token
- token 存在 KV 中，全局同步
- 独立详情页添加 noindex 标签（不被搜索引擎收录）

### 9.7 性能优化
- 产品区图片懒加载（Intersection Observer）
- 产品列表分页默认 25 条/页
- KV 缓存热点分类数据和产品列表
- 图片自动压缩 WebP + 生成缩略图（Cloudflare Images）

### 9.8 SEO 基础设施
- 前台页面自动生成 sitemap.xml
- 自动生成 robots.txt（排除 /b2b /showcase /admin）
- 展示区独立详情页添加 noindex 标签
- 产品详情页输出 schema.org Product 结构化数据
- 多语言页面输出正确 hreflang 标签

### 9.9 GDPR 合规
- 欧盟 IP 访客首次访问弹出 Cookie 同意弹窗
- 同意记录存 Neon 数据库（gdpr_consents 表）
- 隐私政策页包含 GDPR 数据权利说明

> 📝 施工中变更：GDPR 同意记录实际存 Neon（gdpr_consents 表），非原定的 D1

### 9.10 小白友好（后台操作）
- 所有按钮必须有图标 + 汉字
- 所有输入框有标签、占位提示、说明文字
- 危险操作（删除）需要二次确认
- 帮助内容集中在独立「操作指南」页（/admin/guide）

> 📝 施工中变更：「每个后台页面有 ❓ 帮助按钮」未实现，实际帮助入口为独立的操作指南页（五教程手风琴）
