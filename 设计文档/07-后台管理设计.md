# 懿泉茶业 YiQuanTea.com — 后台管理设计

> **版本**: v1.0（Cloudflare 全栈版） | **日期**: 2026-08-11
>
> **本文档定位**：后台 18 个管理模块的"操作界面规格"——每个页面的布局、功能按钮、交互逻辑。
> **阅读对象**：开发人员 + 运营人员。

---

## 一、功能变化说明

> 后台操作**99% 和老版完全一样**。按钮位置、操作流程、页面布局都没变。改了底层的数据库和缓存，但界面和交互不变。

| 模块 | 变化 | 说明 |
|:-----|:-----|:-----|
| 全部模块 | **完全没变** | 界面和操作逻辑 100% 对齐老版 |
| 备份管理 | **操作不变，底层更稳** | 手动备份按钮还在，但底层从 pg_dump 换成 R2 导出；恢复更快 |
| 权限收紧 | **B2B 密码查看仅 admin** | editor 角色不再能查看 B2B 明文密码 |

## 三、各模块概览

### 3.1 仪表盘 (`/admin/dashboard`)

统计卡片：产品总数 / 上架产品数 / B2B 分类数 / 待处理询价 / 待处理样品 / 未读消息 / 今日浏览 / 本月浏览

### 3.2 ★ B2B 展示区管理 (`/admin/showcase`)

**主列表：**
- 分类表格：名称 / 产品数 / 密码状态 / 操作按钮
- 操作按钮：✏️编辑 / 🔑密码 / 📥下载二维码 / 👁️预览 / 🗑️删除

**添加/编辑弹窗：** 中英文名称 / 封面图 / 中英文描述 / 访问密码 / 排序号

**密码管理弹窗：**
- 显示当前密码（需二次验证才能在 👁️ 查看明文）
- 输入新密码
- 随机生成 8 位密码按钮
- 修改后提示"旧密码 24 小时内仍有效"

### 3.3 产品管理 (`/admin/products`)

增强的编辑弹窗含 5 个标签页：
1. **基本信息**：名称/SKU/分类/价格/规格/状态
2. **图片管理**：上传/排序/删除产品图
3. **🎬 视频/360°**：上传视频（MP4/MOV ≤50MB）或 360° 图片集（24-36 张）
4. **📐 详情页布局**：拖拽 7 种区块排序 + 显示/隐藏开关
5. **📱 展示区设置**：多选 B2B 分类 / 展示区默认语言 / 价格显示开关

### 3.4 ★ 询价管理 + 聊天 (`/admin/inquiries`)

**左右分栏布局：**
- 左侧 30%：询价列表（状态标记 / 客户名 / 产品 / 时间 / 未读角标）
- 右侧 70%：微信风格聊天窗口
  - 客户消息：左对齐灰底
  - 员工消息：右对齐品牌绿底白字
  - 每条消息带时间戳 + 已读标记
  - 底部输入框 + Enter 发送 + 📎 附件上传

### 3.5 ★ 样品管理 (`/admin/samples`)

列表筛选：全部 / 新申请 / 处理中 / 已发货 / 已关闭

详情弹窗：申请人信息 / 样品需求 / 状态流转下拉 / 物流单号输入 / 状态历史

### 3.6 ★ 客户行为分析 (`/admin/analytics`)

三个标签页：

**📊 总览：** 统计卡片（总浏览/产品数/国家数/平均时长）+ 每日趋势图 + 来源分布饼图

**🇨🇳 地域：** 国家浏览排名 + 国家×产品热度矩阵

**📦 产品：** TOP 20 热门产品排行（浏览量/平均时长/涉及国家数）

### 3.7 ★ 备份管理 (`/admin/backup`)

- 自动备份状态（上次备份时间/文件大小/下次备份时间）
- **只显示状态，不提供"下载"按钮**——需要下载备份文件时联系管理员从 R2 后台下载
- 手动备份按钮

### 3.8-3.18 其余模块

| 模块 | 说明 | 变化 |
|:-----|:-----|:-----|
| 评论管理 | 审核/发布/删除评价 | 不变 |
| 首页编辑 | Hero图/卖点/认证/CTA | 不变 |
| 导航编辑 | 导航菜单项增删改排序 | 不变 |

| 员工管理 | 三种角色 + 状态管理 | ★password≥8位 + 最后admin保护 |
| 操作日志 | 只读查看，不可修改 | 不变 |
| 网站设置 | 品牌色/字体/联系信息/GDPR/hCaptcha | 新增GDPR/hCaptcha配置区 |
| SEO设置 | 各页面title/desc/keywords/hreflang | 新增hreflang开关 |

## 四、后台路由清单（19 个页面）

```
src/app/admin/
├── page.tsx                  # 登录页
├── layout.tsx                # 后台整体布局
├── dashboard/page.tsx        # 仪表盘
├── products/page.tsx         # 产品管理
├── showcase/page.tsx         # B2B展示区管理
├── inquiries/page.tsx        # 询价管理+聊天
├── samples/page.tsx          # 样品管理
├── reviews/page.tsx          # 评论管理
├── homepage/page.tsx         # 首页编辑
├── navigation/page.tsx       # 导航编辑
├── social/page.tsx           # 社交媒体
├── pages/page.tsx            # 页面内容
├── staff/page.tsx            # 员工管理
├── analytics/page.tsx        # 客户行为分析
├── backup/page.tsx           # 备份管理
├── logs/page.tsx             # 操作日志
├── settings/page.tsx         # 网站设置
```
