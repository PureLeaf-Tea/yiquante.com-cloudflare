## 〇、后台入口

1. 打开浏览器，输入：`https://yiquantea.com/admin`
2. 输入手机号（账号）和密码
3. 点"登录"

> ⚠️ 输错 5 次锁定 15 分钟。忘记密码找管理员重置。
> ⚠️ 登录后 1 小时没操作会自动退出，需要重新登录。

## 一、★ B2B 展示区管理

### B2B 展示区是什么？

前台网站上有一个"B2B产品"入口。批发客户点进去能看到不同的产品分类卡片。每个分类需要密码才能查看里面的产品。密码由销售人员私下发给客户。

### 怎么添加 B2B 分类？

1. 左侧菜单 → 📱 展示区管理
2. 点 [+ 添加新分类]
3. 填写：中文名 / 英文名 / 封面图（可选）/ 描述（可选）/ **访问密码**（必填）
4. 点 💾 保存

### 怎么修改密码？

1. 展示区管理页 → 找到分类 → 点 🔑 密码
2. 点 [👁️ 查看明文]（需输入自己的后台密码验证）
3. 或者输入新密码 → 保存
4. 点 [🎲 随机生成] 自动生成 8 位密码

> ⚠️ 修改密码后，已有权限的客户 24 小时内仍可用旧密码。24 小时后自动失效。

### 怎么把产品加到 B2B 分类里？

1. 左侧菜单 → 📦 产品管理
2. 找到产品 → ✏️ 编辑
3. 切到 📱 展示区设置 标签页
4. 勾选要加入的 B2B 分类
5. 💾 保存

## 二、★ 询价管理 + 在线聊天

### 怎么查看和回复客户询价？

1. 左侧菜单 → 💬 询价管理
2. 左侧是询价列表，右侧是聊天窗口
3. 点某条询价 → 右侧显示聊天记录
4. 底部输入框打字 → 点发送（或按 Enter 键）
5. 发图片：点 📎 → 选文件 → 发送

聊天窗口是微信风格：客户消息在左边（灰底），你的回复在右边（绿底白字）。

### 客户怎么跟我们聊天？

客户提交询价后会收到邮件，邮件里有链接。点链接就能打开聊天窗口，不用注册、不用登录。

### 询价状态说明

| 状态 | 含义 |
|:-----|:-----|
| 🆕 新询价 | 客户刚提交的，还没人看过 |
| ● 处理中 | 正在沟通中 |
| ✓ 已回复 | 已经回复客户，等待客户回复 |
| ✕ 已关闭 | 沟通结束或无合作意向 |

## 三、★ 样品管理

### 怎么处理样品申请？

1. 左侧菜单 → 📋 样品管理
2. 上方筛选：全部 / 新申请 / 处理中 / 已发货 / 已关闭
3. 点 👁️ 查看详情
4. 改状态：
   - 收到申请后 → 改为"处理中"
   - 寄出样品后 → 改为"已发货" + 填物流单号
   - 客户收到后 → 改为"已签收"
   - 取消时 → 改为"已关闭"

## 四、★ 看数据分析

1. 左侧菜单 → 📊 分析
2. 三个标签页：
   - 📊 总览：总体浏览量、来源分布
   - 🇨🇳 地域：哪些国家的人在看
   - 📦 产品：哪些产品最受欢迎

## 五、★ 数据库备份

1. 左侧菜单 → 💾 备份
2. 看到自动备份状态（每天凌晨 3 点自动备份）
3. 需要立即备份：点 [🔄 立即手动备份]

> 📝 施工中变更：定时自动备份（Workers Cron）尚未上线，当前只有手动备份可用（导出 JSON 存入 R2）；上线部署 Cron 后自动备份才生效

## 八、权限说明

| 角色 | 能做什么 | 不能做什么 |
|:-----|:-----|:-----|
| **管理员**（admin） | 所有操作 | — |
| **编辑**（editor） | 管理产品、分类、评论、首页、导航 | 不能管理员工、不能看 B2B 明文密码、不能看备份 |
| **客服**（customer_service） | 查看和回复询价、管理样品、聊天 | 不能改产品和分类 |

## 常见操作问题

**Q：上传图片后前台不显示？**
→ 等 1-2 分钟，确认后台编辑页有预览图

**Q：客户说密码正确但进不去 B2B 区？**
→ 去展示区管理确认密码，提醒客户清缓存或换浏览器，看看有没有被锁定

**Q：后台被自动退出？**
→ 1 小时没操作就会自动退出，重新登录就行
