## 一、★ B2B 展示区管理

### B2B 展示区是什么？

前台网站上有一个"B2B产品"入口。批发客户点进去能看到不同的产品分类卡片。每个分类需要密码才能查看里面的产品。密码由销售人员私下发给客户。

### 怎么添加 B2B 分类？

1. 左侧菜单 → 📱 展示区管理
2. 点 [+ 添加新分类]
3. 填写：中文名 / 英文名 / 封面图（可选）/ 描述（可选）/ **访问密码**（必填）
4. 点 💾 保存

### 怎么修改密码？

1. 展示区管理页 → 找到分类 → 点 🔑 密码
2. 点 [👁️ 查看明文]（需输入自己的后台密码验证）
3. 或者输入新密码 → 保存
4. 点 [🎲 随机生成] 自动生成 8 位密码

> ⚠️ 修改密码后，已有权限的客户 24 小时内仍可用旧密码。24 小时后自动失效。

### 怎么把产品加到 B2B 分类里？

1. 左侧菜单 → 📦 产品管理
2. 找到产品 → ✏️ 编辑
3. 切到 📱 展示区设置 标签页
4. 勾选要加入的 B2B 分类
5. 💾 保存

## 二、★ 询价管理 + 在线聊天

### 怎么查看和回复客户询价？

1. 左侧菜单 → 💬 询价管理
2. 左侧是询价列表，右侧是聊天窗口
3. 点某条询价 → 右侧显示聊天记录
4. 底部输入框打字 → 点发送（或按 Enter 键）
5. 发图片：点 📎 → 选文件 → 发送

聊天窗口是微信风格：客户消息在左边（灰底），你的回复在右边（绿底白字）。

### 客户怎么跟我们聊天？

客户提交询价后会收到邮件，邮件里有链接。点链接就能打开聊天窗口，不用注册、不用登录。

### 询价状态说明

| 状态 | 含义 |
|:-----|:-----|
| 🆕 新询价 | 客户刚提交的，还没人看过 |
| ● 处理中 | 正在沟通中 |
| ✓ 已回复 | 已经回复客户，等待客户回复 |
| ✕ 已关闭 | 沟通结束或无合作意向 |

## 三、★ 样品管理

### 怎么处理样品申请？

1. 左侧菜单 → 📋 样品管理
2. 上方筛选：全部 / 新申请 / 处理中 / 已发货 / 已关闭
3. 点 👁️ 查看详情
4. 改状态：
   - 收到申请后 → 改为"处理中"
   - 寄出样品后 → 改为"已发货" + 填物流单号
   - 客户收到后 → 改为"已签收"
   - 取消时 → 改为"已关闭"

## 九、★ 首页轮播图管理（大图区）

### 轮播图是什么？

客户打开网站，第一眼看到的最顶部大图区域，**每 5 秒自动换一张**。电脑和手机各有各的一套图。

### 在哪里管理？

左侧菜单 → 🏠 首页编辑，里面有两个区块：

- **「Hero 轮播图（电脑端）」**：给用电脑的客户看
- **「Hero 轮播图（手机端）」**：给用手机的客户看

两个区块**各自独立**添加、删除、排序，互不影响，数量也不要求一样。

### ★ 图片比例规范（最重要，传图前先裁好）

| 端 | 比例 | 常见尺寸（照着裁就行） |
|:---|:---|:---|
| 电脑图 | **12:5 横图** | 1920×800、2400×1000 |
| 手机图 | **5:6 竖图** | 750×900、900×1080 |

- **只认比例，不卡像素**：大一点小一点都可以，比例裁对最重要
- 怎么裁：用手机相册自带的"裁剪/编辑"功能，选择 12:5（电脑图）或 5:6（手机图）比例，裁好再上传
- ⚠️ 比例没裁对，网页会自动切掉多余的部分——会出现**人头被削、产品被切掉一半**，所以务必先裁图

### 每端放多少张？

**不超过 15 张**，每张 5 秒自动切换。别放太多——客户停留时间有限，后面的图没人看得到。

### 标题、副标题、跳转链接

每张图都可以填：标题（图上那行大字）、副标题（大字下面的小字）、跳转链接（点击图片跳去的页面）。**留空就不显示文字**——图里已经印了字的，不用再填。

### 手机端没传图会怎样？

手机端列表空着时，用手机的客户会**自动看到电脑端的图（裁剪版）**。想效果好，建议手机端也配上图。

### 上传步骤

1. 先把图按比例裁好（见上表）
2. 左侧菜单 → 🏠 首页编辑
3. 选"电脑端"或"手机端"区块 → [＋ 添加]
4. 上传图片 → 填标题（可不填）→ 点 💾 保存
5. 新图自动排到轮播末尾，需要调整顺序的拖动排序

## 常见操作问题

**Q：上传图片后前台不显示？**
→ 等 1-2 分钟，确认后台编辑页有预览图

**Q：客户说密码正确但进不去 B2B 区？**
→ 去展示区管理确认密码，提醒客户清缓存或换浏览器，看看有没有被锁定

**Q：后台被自动退出？**
→ 1 小时没操作就会自动退出，重新登录就行

**Q：上传的图显示出来被切掉一块？**
→ 比例没裁对。电脑图按 12:5、手机图按 5:6 重新裁剪后再传。

**Q：手机上看到的图是横的、被裁得不好看？**
→ 因为手机端还没配图，显示的是电脑图裁剪版。去「Hero 轮播图（手机端）」区块加上竖图就好了。
