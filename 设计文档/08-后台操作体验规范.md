# 懿泉茶业 YiQuanTea.com — 后台操作体验规范

> **版本**: v1.0（Cloudflare 全栈版） | **日期**: 2026-08-11
>
> **本文档定位**：给开发人员和 UI 设计人员的"操作规范手册"——让不懂代码的员工也能独立完成所有后台操作。
> **核心原则**：所有按钮必须有图标+汉字；所有输入框有说明文字；所有危险操作有二次确认。

---

## 一、按钮规范

### 1.1 图标+汉字（强制）

```
✅ 正确：[📦 添加新产品]  [🔑 修改密码]  [👁️ 预览效果]
❌ 错误：[ADD]  [Submit]  [OK]
```

### 1.2 图标映射表

| 操作 | 图标 | 按钮文案示例 |
|:-----|:-----|:-----|
| 新增 | ➕ | 添加 / 新增分类 |
| 编辑 | ✏️ | 编辑 / 修改 |
| 删除 | 🗑️ | 删除 |
| 保存 | 💾 | 保存 / 保存修改 |
| 取消 | ❌ | 取消 |
| 确认 | ✅ | 确认 / 确定 |
| 预览 | 👁️ | 预览 |

| 上传 | 📤 | 上传图片 / 上传视频 |

### 1.3 危险操作确认

删除操作必须二次确认（输入名称确认）：

```
┌─ 确认删除 ──────────────────────────────┐
│  ⚠️ 此操作不可恢复！                      │
│  请输入要删除的（分类/产品）名称以确认：     │
│  ┌──────────────────────────────┐       │
│  │                              │       │
│  └──────────────────────────────┘       │
│  [  取  消  ]     [  🗑️ 确认删除 ]      │
└─────────────────────────────────────────┘
```

## 二、输入框规范

### 2.1 三要素（缺一不可）

```
  产品中文名 *                        ← 标签（带必填标记 *）
  ┌──────────────────────────┐       ← 输入框
  │ 请输入产品中文名称         │       ← 占位提示
  └──────────────────────────┘
  前台显示的产品名，客户会看到           ← 说明文字（灰色小字）
```

### 2.2 实时验证

- 输入时实时检查格式
- 错误：输入框红色边框 + 红色提示文字
- 正确：输入框绿色边框
- 保存按钮在验证通过前禁用（灰色不可点击）

### 2.3 密码输入框特殊处理

- `autocomplete="off"`（禁止浏览器保存密码）
- 👁️ 眼睛图标切换明文/密文
- B2B 密码弹窗额外：查看明文需二次输入管理员密码验证

## 三、弹窗规范

### 3.1 弹窗结构

```
┌─ 弹窗标题 ─────────────────── ✕ ──────┐
│                                        │
│  弹窗内容区                              │
│                                        │
├────────────────────────────────────────┤
│  [  取  消  ]         [  💾 保  存  ]   │
└────────────────────────────────────────┘
```

- 桌面：居中显示，最大宽 600px
- 手机：全屏显示，无圆角
- 背景遮罩：半透明黑色 60%

## 四、操作反馈

### 4.1 Toast 提示

| 操作 | 提示文字 | 颜色 |
|:-----|:-----|:-----|
| 保存成功 | "✅ XX 已保存" | 绿色 |
| 删除成功 | "✅ XX 已删除" | 绿色 |

Toast 显示 3 秒后自动消失，右上角弹出。

## 六、帮助系统

每个后台页面右上角有 ❓ 帮助按钮。点击弹出当前页面的专用帮助说明。

**B2B 展示区帮助内容示例：**

> 📌 B2B展示区是什么？
> 前台网站上有一个"B2B产品"入口，批发客户可以点击进入看到不同的产品分类卡片。每个分类需要密码才能查看产品。
>
> 📌 怎么添加产品到分类？
> 去 📦 产品管理 → ✏️ 编辑产品 →切到 📱 展示区设置 → 勾选要加入的 B2B 分类 → 💾 保存
>
> 📌 密码规则
> 密码验证通过后 24 小时内无需再次输入。修改密码后，已有权限的客户 24 小时内仍可用旧密码访问。
